# Tahir Bakery ERP — Releases

This repository contains official public releases of **Tahir Bakery ERP**.

The application source code is maintained in a separate private repository. This repository is used only for distributing released desktop application installers and update metadata.

## Downloads

Download the latest version from the **Releases** section:

* Windows Installer (`.exe`)
* Release notes
* Update metadata

## Installation

1. Download the latest Windows installer from the latest GitHub Release.
2. Run the installer.
3. Follow the installation instructions.
4. Launch **Tahir Bakery ERP**.

If you already have Tahir Bakery ERP installed, use the application's built-in **Check for Updates** option when available.

## Updating

Tahir Bakery ERP supports application updates through the configured release channel.

When a new version is published:

1. A new GitHub Release is created.
2. The new installer/update files are uploaded.
3. The ERP checks the release information.
4. Users with a valid installation can download and install the update.

Your existing bakery data is intended to remain separate from the application update.

## Releases

All official versions are published through GitHub Releases.

Each release should include:

* Version number
* Windows installer
* Release notes
* Required update metadata/files

## Security & Licensing

Tahir Bakery ERP uses an application licensing system to control authorized installations.

A valid license may be required to activate and use the application.

License information is managed separately from this public release repository.

Do not publish:

* License keys
* Device fingerprints
* Private API credentials
* Signing keys
* Encryption keys
* Database files
* Customer data
* Private source code
* Internal configuration
* Server credentials

If you believe a release contains a security issue, please contact the software provider directly rather than publicly posting sensitive information.
